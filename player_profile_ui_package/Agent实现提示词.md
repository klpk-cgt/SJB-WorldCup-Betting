# Agent / Codex 实现提示词

你可以直接把下面这段提示词发给 Agent，并同时附上：

1. 当前资料页面 HTML / JSX 文件
2. 满意的参考图
3. `资料页面重构说明文档.md`
4. `assets` 素材目录

---

## 一次性完整提示词

```text
你现在需要重构我的世界杯竞猜网页中的“资料页面 / 玩家中心”UI。

我已经提供：
1. 当前页面 HTML / JSX 文件
2. 一张满意的参考图
3. 资料页面重构说明文档
4. assets 素材包

请严格按照说明文档和参考图进行实现。

核心要求：

1. 只重构视觉和布局，不改变现有数据结构和字段含义。
2. 页面必须接近参考图：浅色背景、世界杯体育场氛围、白色大卡片、轻毛玻璃、柔和阴影、绿色主色、少量蓝色点缀。
3. 保留所有模块：
   - 顶部 Player Center
   - 刷新 / 分享 / 退出按钮
   - 玩家资料卡
   - 总览 / 战报 / 徽章 / 道具 Tab
   - 四个统计卡
   - 徽章进度
   - 最近战报
   - 长期预测
   - 保存战绩图 / 退出按钮
4. 禁止改成深色电竞风、黑金风、赛博朋克风。
5. 禁止把页面做成图片，必须是真实前端组件。
6. 优先使用 Tailwind CSS。
7. 移动端优先，桌面端居中显示，最大宽度 max-w-lg。
8. 如果需要图标，优先使用 assets 素材包中的 SVG，或使用 lucide-react。
9. 代码要清晰、可维护，不要引入复杂 UI 库。
10. 完成后请自查是否符合说明文档中的验收清单。

请直接修改相关页面文件，并给出修改说明。
```

## 更严格的防偏差提示词

如果 Agent 经常自由发挥，可以追加这段：

```text
注意：参考图是最终目标，不是灵感来源。请不要重新设计另一套风格。你需要尽量复刻参考图中的布局节奏、浅色背景、顶部体育场氛围、白色卡片、圆角、阴影、绿色主色和资料页结构。任何明显偏离参考图的设计都视为失败。
```

## 分步骤开发提示词

如果你想让 Agent 更稳，可以不要一次性让它全改，而是分三步：

### 第一步：只改设计系统和页面骨架

```text
先不要细化所有模块，只完成资料页面的整体设计系统和页面骨架：
- 浅色背景
- 顶部 Header
- Player Center 顶部导航
- 玩家资料主卡片
- max-w-lg 移动端容器
- 引入 assets 背景和装饰图

不要改数据字段。
完成后停下来，让我确认。
```

### 第二步：重构主内容模块

```text
在已确认的页面骨架基础上，继续重构：
- Tab 导航
- 四个统计卡
- 徽章进度
- 最近战报
- 长期预测

保持参考图风格一致。
不要重新设计顶部。
```

### 第三步：统一细节和验收

```text
请统一检查整个资料页面：
- 间距
- 字体大小
- 阴影
- 圆角
- 颜色
- 移动端适配
- 是否接近参考图

并根据说明文档的验收清单逐项修正。
```

```text
不要删除现有业务逻辑。
不要改接口字段。
不要改路由。
不要影响其他页面。
如果需要新增素材路径，请集中放在 public/assets/player-profile/。
如果项目已有组件系统，请尽量复用。
```
