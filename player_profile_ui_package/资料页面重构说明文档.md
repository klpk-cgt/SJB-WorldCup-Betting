# 世界杯竞猜网页 · 资料页面重构说明文档

> 目标：让 Agent 稳定生成接近参考图的“浅色、高级、世界杯玩家中心”资料页面。  
> 使用方式：将本说明文档、参考图、当前页面 HTML 一起提供给 Agent，让它按文档重构 UI，不要自由发挥。  
> 适用页面：资料页面 / 玩家中心 / Player Center。

---

## 1. 重构目标

当前页面的数据结构已经完整，重构时只优化视觉表现和组件布局，不改变字段含义。

页面最终效果应接近参考图：

- 浅色背景
- 体育场氛围
- 大圆角卡片
- 轻毛玻璃效果
- 柔和阴影
- 绿色主色
- 少量蓝色点缀
- 金色用于奖杯、段位、荣誉
- 移动端优先
- 有世界杯主题，但不做成深色电竞风

## 3. 页面风格定位

### 3.1 风格关键词

请严格围绕以下关键词设计：

```text
浅色、清爽、高级、世界杯、玩家中心、轻毛玻璃、柔和阴影、移动端优先、卡片式、圆角、绿色主色、蓝色点缀、金色荣誉感
```

### 3.2 禁止方向

不要出现以下风格：

```text
深色电竞风、黑金风、赛博朋克、强霓虹、大面积深绿背景、复杂炫光、低质游戏 UI、拥挤后台表格风
```

### 3.3 设计参考目标

参考图不是灵感，而是最终视觉目标。  
Agent 应尽量复刻参考图的：

- 浅色体育场背景
- 顶部空气感
- 白色大卡片
- 头像与资料布局
- 绿色主色
- 轻阴影
- 高级、干净的卡片层级

## 5. 页面布局

### 5.1 页面容器

```html
<body class="min-h-screen bg-[#f6f8fb] text-slate-900">
  <div class="mx-auto min-h-screen max-w-lg overflow-hidden">
    ...
  </div>
</body>
```

说明：

- 页面最大宽度 `max-w-lg`
- 桌面端居中
- 移动端铺满
- 内容左右边距 16px

### 5.2 顶部 Header

建议高度：230px - 260px。

结构：

```text
Header
├─ 顶部导航
│  ├─ Player Center 标题
│  └─ 刷新 / 分享 / 退出按钮
├─ 装饰图层
│  ├─ 体育场背景
│  ├─ 世界杯奖杯
│  └─ 足球装饰
└─ 玩家资料主卡片
```

注意：

- 体育场背景要浅，不要压暗。
- 奖杯和足球只作为右上角装饰，透明度 0.45 - 0.75。
- 不要让背景影响文字可读性。

### 5.3 资料卡布局

参考结构：

```text
资料卡
├─ 上半部分
│  ├─ 头像
│  └─ 用户信息
│     ├─ 昵称 + 认证
│     ├─ 段位
│     ├─ 标签
│     └─ 描述
├─ 中部数据
│  ├─ 当前积分
│  ├─ 净收益
│  └─ 等级进度
└─ 进度条
```

移动端建议：

- 头像 84px - 96px
- 卡片内边距 20px - 24px
- 昵称字号 28px - 32px
- 数字字号 24px - 32px

```css

  transition: transform 0.2s ease, box-shadow 0.2s ease;

  transform: translateY(-2px);

}
```

```css

  transition: width 0.8s cubic-bezier(0.22, 0.61, 0.36, 1);
```
